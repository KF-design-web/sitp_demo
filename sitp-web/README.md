## Development server

To start a local development server, run:

```bash
ng serve --proxy-config proxy.conf.json
```

> **Project note (2026-09-24):** ALWAYS serve with the proxy config — `npm start`
> does this for you. The proxy forwards `/api/*` to the Spring Boot backend on
> `:8080`, so the browser stays on one origin and the session cookie flows
> without CORS. A bare `ng serve` looks like it works, then every login dies
> with a red CORS error — the proxy is the fix, not CORS headers.

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
